# Materiais de Aulas — Análise e Desenvolvimento de Sistemas

Repositório com os materiais utilizados nas aulas de **Desenvolvimento Front-end**, parte do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

## Estrutura do Repositório

```
materiais-aulas-ads-frontend/
├── Fase3_Desenvolvimento_Front_end.docx   # Documento geral da Fase 3
├── Aula 1 - Ferramentas de Desenvolvimento/
│   ├── Ferramentas_Desenvolvimento_Frontend.docx
│   └── slides_aula2_ferramentas_desenvolvimento (1).pptx
├── Aula 2 - SASS e CSS Avançado/
│   ├── apostila_aula3_sass_css_avancado.docx
│   └── exemplos/                          # Projetos práticos com Vite + SCSS
├── Aula 3 - ES6 e ECMAScript 6/
│   ├── Apostila_ES6_ECMAScript6.docx
│   └── index.js
├── Aula 4 - TypeScript/
│   └── Apostila_TypeScript.docx
└── Aula 5 - React/
    ├── React-basico.pdf
    └── ReactJS.pptx
```

## Conteúdo

### Aula 1 — Ferramentas de Desenvolvimento Frontend
Apresentação e material sobre as principais ferramentas utilizadas no desenvolvimento front-end moderno.

### Aula 2 — SASS e CSS Avançado
Apostila e exemplos práticos sobre SASS/SCSS: variáveis, nesting, parciais, mixins e CSS Custom Properties. Os exemplos interativos estão em `Aula 2 - SASS e CSS Avançado/exemplos/` (projetos Node.js com Vite).

### Aula 3 — ES6 / ECMAScript 6
Apostila com os conceitos e funcionalidades introduzidos no ECMAScript 6, como `let`/`const`, arrow functions, destructuring, spread/rest, modules, classes, Promises e mais.

### Aula 4 — TypeScript
Apostila introdutória ao TypeScript: tipagem estática, interfaces, tipos primitivos e compostos, generics, enums, decorators e integração com projetos JavaScript modernos.

### Aula 5 — React
Material introdutório de React com conteúdo em PDF e apresentação para os primeiros conceitos da biblioteca.
